# Documentation site

The bilingual project documentation is a Next.js and Fumadocs app. Page content lives in `content/docs/`; the AI-facing English and Chinese indexes are `index.md` and `index.zh-CN.md`.

Run the development server from this directory:

```bash
bun run dev
```

See the repository [README](../README.md) for project setup and the documentation indexes for page links.
